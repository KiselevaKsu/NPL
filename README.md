Учебная индивидуальная работа. Каждая задача выполняется на своём языке
программирования — всего 20 задач на 20 разных языках. Специализированные
библиотеки не используются: только стандартные средства языков и стандартные
модули для работы с потоками, сокетами, файлами и разбором данных.

## Темы

1. **Многопоточность** — параллельные вычисления, синхронизация, обмен данными
   между потоками и процессами.
2. **Алгоритмические задачи** — классические алгоритмы, в том числе с рекурсией
   (не менее двух рекурсивных).
3. **Ввод/вывод в консоль и файл** — консольные программы с сохранением
   состояния и отчётами в файлах.
4. **Клиент-серверное взаимодействие** — сокеты, обработка нескольких клиентов,
   рассылка сообщений.
5. **Конвертация данных** — преобразование между форматами (CSV, JSON, INI,
   HTML, Markdown, пользовательские текстовые форматы).

## Структура репозитория

Исходники каждой задачи лежат в папке своей темы:

```
NPL/
├── 1_threads/
│   ├── task_1_ada/
│   ├── task_2_d/
│   ├── task_3_nim/
│   └── task_4_ruby/
├── 2_algorithms/
│   ├── task_1_prolog/
│   ├── task_2_fsharp/
│   ├── task_3_kotlin/
│   └── task_4_julia/
├── 3_io/
│   ├── task_1_groovy/
│   ├── task_2_objc/
│   ├── task_3_scala/
│   └── task_4_haskell/
├── 4_client_server/
│   ├── task_1_rust/
│   ├── task_2_erlang/
│   ├── task_3_swift/
│   └── task_4_scheme/
└── 5_convert/
    ├── task_1_clojure/
    ├── task_2_lua/
    ├── task_3_ocaml/
    └── task_4_zig/
```

Каждая задача ведётся в отдельной git-ветке. Имя ветки:
`<номер темы>_task<номер задачи>_<язык>`, например `1_task1_ada`.
Подробное описание задачи, инструкции по сборке и запуску лежат
в `README.md` внутри папки соответствующей задачи.

## Требования

Для сборки и запуска каждой задачи нужен соответствующий компилятор
или интерпретатор. Точный список и команды для каждой задачи указаны
в её собственном `README.md`.
