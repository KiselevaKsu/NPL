# Задача 1.4. Параллельный подсчёт суммы элементов массива

## Тема

Многопоточность.

## Язык

Ruby.

## Условие

Дан массив чисел. Нужно вычислить сумму всех его элементов.
Требуется реализовать **параллельную** версию: массив разбивается
на `T` частей, каждая часть суммируется в своём потоке, затем
частичные суммы складываются в общий результат под `Mutex`.
Дополнительно реализуется последовательная версия для сравнения
времени работы.

## Что демонстрирует

- создание потоков через класс `Thread`;
- защиту разделяемой переменной с помощью `Mutex`;
- разделение массива на блоки и объединение частичных результатов;
- сравнение времени параллельной и последовательной версий.

## Сборка и запуск

Требуется интерпретатор Ruby (версия 2.5+).

```bash
ruby sum_array.rb
```

## Формат ввода

Параметры задаются константами или аргументами командной строки:
- длина массива `N`;
- число потоков `T`.

Массив заполняется случайными числами.

## Формат вывода

```
Последовательная версия: sum = ..., время = ... мс
Параллельная версия:     sum = ..., время = ... мс, потоков = T
```

## Примечания

Специализированные библиотеки не используются — только стандартные
средства Ruby (`Thread`, `Mutex`, `Benchmark`) из стандартной
поставки.
