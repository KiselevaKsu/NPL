# Задача 1.3. «Читатели–писатели» для банковского счёта

[📹 Видео-демонстрация](https://disk.yandex.ru/i/2zz8d1PxdxILzA)

## Тема

Многопоточность.

## Язык

Nim.

## Условие

Есть общий банковский счёт с балансом. Несколько потоков-читателей
периодически запрашивают текущий баланс. Несколько потоков-писателей
выполняют операции пополнения и снятия. Если писатель пытается снять
больше, чем есть на счёте, он ждёт, пока баланс не станет достаточным.

Требуется реализовать модель **«читатели–писатели»** с корректной
синхронизацией: читатели не должны блокировать друг друга, писатели
получают монопольный доступ, при нехватке средств писатель ждёт
на условной переменной.

## Что демонстрирует

- работу с разделяемой переменной (баланс счёта) из нескольких потоков;
- синхронизацию через `Lock` и `Cond`;
- ожидание условия (нехватка средств) без busy-wait;
- подсчёт числа операций и итогового баланса.

## Сборка и запуск

Требуется компилятор Nim.

```bash
nim c -r --threads:on bank.nim
```

Флаг `--threads:on` обязателен для работы с потоками.

## Формат ввода

Параметры задаются константами или аргументами командной строки:
- число читателей;
- число писателей;
- число операций на поток;
- начальный баланс.

## Формат вывода

```
Начальный баланс: ...
Читателей: ..., писателей: ...
Операций чтения: ..., операций записи: ...
Итоговый баланс: ...
Все потоки завершены корректно.
```

## Примечания

Специализированные библиотеки не используются — только стандартные
модули Nim (`threads`, `locks`, `os`) из стандартной поставки.
