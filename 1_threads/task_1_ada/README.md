# Задача 1.1. Параллельное скалярное произведение векторов

[Видео-демонстрация](https://disk.yandex.ru/i/w-7diyMggDzlcg)

## Тема

Многопоточность.

## Язык

Ada.

## Условие

Даны два вектора одинаковой длины `N`. Нужно вычислить их скалярное
произведение:

```
sum = a[1]*b[1] + a[2]*b[2] + ... + a[N]*b[N]
```

Требуется реализовать **параллельную** версию: вектор разбивается на
несколько частей, каждая часть обрабатывается отдельной задачей
(`task` в терминах Ada). Частичные суммы передаются главной задаче
через механизм рандеву и складываются. Дополнительно реализуется
последовательная версия для сравнения времени работы.

## Что демонстрирует

- создание и запуск Ada-задач (`task type`, `task body`);
- механизм рандеву (`entry`, `accept`) для передачи частичных сумм
  главной задаче;
- сравнение времени параллельной и последовательной версий.

## Сборка и запуск

Требуется компилятор GNAT (входит в GCC Ada).

```bash
gnatmake scalar_product.adb
./scalar_product
```

## Формат ввода

Программа либо генерирует векторы случайными числами заданной длины,
либо читает их из файла. Длина `N` и число задач `T` задаются
константами или аргументами командной строки.

## Формат вывода

```
Последовательная версия: sum = ..., время = ... мс
Параллельная версия:     sum = ..., время = ... мс, задач = T
```

## Примечания

Специализированные библиотеки не используются — только стандартные
средства языка Ada и пакеты `Ada.Text_IO`, `Ada.Calendar` (или
`Ada.Real_Time`) из стандартной поставки.
