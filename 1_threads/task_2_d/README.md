# Задача 1.2. Параллельная инверсия цвета изображения

[📹 Видео-демонстрация](https://vk.ru/away.php?to=https%3A%2F%2Fdisk.yandex.ru%2Fi%2FxAWv4XoUo43-7g&utf=1)

## Тема

Многопоточность.

## Язык

D.

## Условие

Дан файл изображения в формате PPM (P6, бинарный). Нужно инвертировать
цвет каждого пикселя (каждый канал `c` заменяется на `255 - c`) и
сохранить результат в новый PPM-файл.

Требуется реализовать **параллельную** версию: массив пикселей
разбивается на несколько блоков, каждый блок обрабатывается отдельным
потоком из пула (`core.thread`). Дополнительно реализуется
последовательная версия для сравнения времени работы.

## Что демонстрирует

- работу с пулом потоков через модуль `core.thread`;
- разделение массива данных между потоками;
- чтение и запись бинарного PPM-файла (P6) без сторонних библиотек;
- сравнение времени параллельной и последовательной версий.

## Структура

```
task_2_d/
├── README.md        — этот файл
├── invert.d         — главная программа
└── sample.ppm       — пример входного изображения  
```

## Сборка и запуск

Требуется компилятор DMD или LDC.

```bash
dmd invert.d -of=invert
./invert input.ppm output.ppm
```

Или с LDC:

```bash
ldc2 invert.d -of=invert
./invert input.ppm output.ppm
```

## Формат ввода

- `input.ppm` — изображение в формате PPM P6 (бинарный).
- Число потоков `T` задаётся константой или аргументом командной строки.

## Формат вывода

```
Последовательная версия: время = ... мс
Параллельная версия:     время = ... мс, потоков = T
Результат сохранён в output.ppm
```

## Примечания

Специализированные библиотеки не используются — только стандартные
средства языка D (`std.thread`, `std.stdio`, `std.file`) из
стандартной поставки.
