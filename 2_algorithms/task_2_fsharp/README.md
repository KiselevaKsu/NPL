# Задача 2.2. Обход бинарного дерева в глубину с накоплением пути

## Тема

Алгоритмические задачи.

## Язык

F#.

## Условие

Дано бинарное дерево. Нужно рекурсивно обойти его в глубину и для
каждого листа вывести путь от корня до этого листа и сумму значений
на пути. Дерево задаётся рекурсивным типом, обход реализуется
рекурсивной функцией без мутабельных структур.

## Что демонстрирует

- рекурсию в F#;
- рекурсивный размеченный тип для дерева;
- обход в глубину с накоплением аккумулятора (пути);
- сопоставление с образцом (pattern matching);
- работу с неизменяемыми списками.

## Структура

```
task_2_fsharp/
├── README.md      — этот файл
└── tree.fsx       — главный скрипт
```

## Сборка и запуск

Требуется .NET SDK с установленным F#.

```bash
dotnet fsi tree.fsx
```

## Формат ввода

Дерево задаётся в исходнике (функция `main`) как значение
рекурсивного типа `Tree`.

## Формат вывода

```
Путь: [1; 2; 4], сумма = 7
Путь: [1; 2; 5], сумма = 8
Путь: [1; 3; 6], сумма = 10
```

Для каждого листа — свой путь от корня и сумма значений.

## Примечания

Специализированные библиотеки не используются — только стандартная
библиотека F# (`List`, `printfn`).
