# Задача 2.4. Топологическая сортировка графа через рекурсивный DFS

## Тема

Алгоритмические задачи.

## Язык

Julia.

## Условие

Дан ориентированный граф, заданный списком рёбер. Нужно выполнить
топологическую сортировку вершин — такой линейный порядок, в котором
для каждого ребра `u → v` вершина `u` стоит раньше `v`.

Реализация — рекурсивный обход в глубину (DFS). Вершина добавляется
в результат после обработки всех её соседей (post-order). Если при
обходе обнаруживается обратное ребро (вершина уже в стеке рекурсии),
граф содержит цикл, и топологическая сортировка невозможна.

## Что демонстрирует

- рекурсивный обход в глубину;
- топологическую сортировку через post-order DFS;
- обнаружение циклов в ориентированном графе;
- работу со списками смежности.


## Формат ввода

Граф задаётся в исходнике как список рёбер (массив пар вершин)
или читается из файла.

## Формат вывода

```
Граф: 6 вершин, 6 рёбер
Топологический порядок: 5 4 2 3 1 6
```

Если найден цикл:

```
Граф содержит цикл, топологическая сортировка невозможна.
```
