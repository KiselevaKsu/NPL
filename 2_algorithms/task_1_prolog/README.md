# Задача 2.1. Все перестановки строки перебором с возвратом

## Тема

Алгоритмические задачи.

## Язык

Prolog.

## Условие

Дана строка (список символов). Нужно построить все её перестановки
без повторений. Реализация — рекурсивный предикат `permute/2`,
который на каждом шаге выбирает один элемент из оставшихся,
рекурсивно переставляет остаток и при неудаче откатывается
(backtracking).

## Что демонстрирует

- рекурсию в Prolog;
- перебор с возвратом (backtracking);
- работу со списками: выбор элемента, удаление, конкатенация;
- вывод всех решений через `findall` и подсчёт их количества.

## Структура

```
task_1_prolog/

```

## Сборка и запуск

Требуется интерпретатор SWI-Prolog.

```bash
swipl -q -g "main, halt" -s permutations.pl
```

## Формат ввода

Строка задаётся в исходнике (предикат `main`) или читается
с консоли.

## Формат вывода

```
Все перестановки строки "abc":
abc
acb
bac
bca
cab
cba
Всего перестановок: 6
```

## Примечания

Специализированные библиотеки не используются — только стандартные
предикаты SWI-Prolog (`member`, `select`, `findall`, `length`).
