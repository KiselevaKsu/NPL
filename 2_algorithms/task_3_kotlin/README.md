# Задача 2.3. Наибольшая общая подпоследовательность двух строк

## Тема

Алгоритмические задачи.

## Язык

Kotlin.

## Условие

Даны две строки. Нужно найти их наибольшую общую подпоследовательность
(НОП) — самую длинную последовательность символов, которая встречается
в обеих строках в одном и том же порядке, но не обязательно подряд.

Реализация — динамическое программирование с мемоизацией. Строится
матрица `dp`, где `dp[i][j]` — длина НОП для префиксов `s1[0..i]`
и `s2[0..j]`. Затем обратным проходом по матрице восстанавливается
сама подпоследовательность.

## Что демонстрирует

- динамическое программирование;
- рекурсию с мемоизацией;
- восстановление ответа обратным проходом по матрице;
- работу со строками и двумерными массивами.

## Сборка и запуск

Требуется компилятор Kotlin (`kotlinc`) или `kotlin` для скриптов.

```bash
kotlinc lcs.kt -include-runtime -d lcs.jar
java -jar lcs.jar
```

Или как скрипт:

```bash
kotlin lcs.kt
```

## Формат ввода

Две строки задаются в исходнике (функция `main`) или читаются
с консоли.

## Формат вывода

```
Строка 1: ...
Строка 2: ...
Длина НОП: ...
НОП: ...
```
