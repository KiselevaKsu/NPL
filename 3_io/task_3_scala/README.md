# Задача 3.3. Консольный калькулятор с историей операций

## Тема

Ввод/вывод в консоль и файл.

## Язык

Scala.

## Условие

Консольный калькулятор. Пользователь вводит арифметические выражения
вида `2 + 3`, `10 * 5`, `7 / 2`. Каждое выражение вычисляется,
результат выводится на экран, а само выражение и результат
дописываются в файл истории. При запуске история читается и
выводится на экран. Команда `exit` завершает работу.

## Что демонстрирует

- чтение строк с консоли;
- разбор простого арифметического выражения;
- запись в файл в режиме добавления;
- чтение файла при старте;
- обработку ошибок ввода (деление на ноль, неверный формат).

## Сборка и запуск

Требуется Scala (`scalac` / `scala`) или `scala-cli`.

Через scala-cli:

```bash
scala-cli run Calculator.scala
```

Через scalac:

```bash
scalac Calculator.scala
scala Calculator
```

## Формат ввода

Строки вида:

```
2 + 3
10 * 5
7 / 2
exit
```

Поддерживаются операции `+`, `-`, `*`, `/`.

## Формат вывода

```
История операций:
  2 + 3 = 5
  10 * 5 = 50

> 7 / 2
7 / 2 = 3.5

> exit
До свидания.
```

## Примечания

Специализированные библиотеки не используются — только стандартная
библиотека Scala и JDK (`scala.io.StdIn`, `java.io._`).
