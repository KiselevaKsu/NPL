# Задача 3.2. Частота слов в текстовом файле

## Тема

Ввод/вывод в консоль и файл.

## Язык

Objective-C.

## Условие

Программа читает текстовый файл, разбивает его на слова, считает
частоту каждого слова. Выводит топ-20 самых частых слов в консоль
и дописывает сводку в файл-журнал: дата, имя исходного файла,
общее число слов, топ-20.

## Что демонстрирует

- чтение текстового файла;
- разбиение текста на слова;
- подсчёт частоты через словарь (`NSDictionary` / `NSMutableDictionary`);
- сортировку по убыванию частоты;
- запись отчёта в файл (режим добавления).

## Структура

```
task_2_objc/
├── README.md       — этот файл
├── wordfreq.m      — главная программа
└── input.txt       — пример входного файла
```

## Сборка и запуск

Требуется clang с поддержкой Objective-C и фреймворк Foundation.

```bash
clang -framework Foundation wordfreq.m -o wordfreq
./wordfreq input.txt
```

## Формат ввода

Один текстовый файл, путь передаётся аргументом командной строки.

## Формат вывода

В консоль:

```
Файл: input.txt
Всего слов: 1234
Топ-20:
  1. the        — 56
  2. and        — 41
  ...
```

В файл-журнал `wordfreq.log` дописывается блок с датой, именем файла
и тем же топ-20.

## Примечания

Специализированные библиотеки не используются — только Foundation
из стандартной поставки.
