# Задача 3.4. Поиск файлов по маске

## Тема

Ввод/вывод в консоль и файл.

## Язык

Haskell.

## Условие

Программа принимает каталог и маску файлов (например `*.txt`).
Рекурсивно обходит каталог и все подкаталоги, для каждого файла
проверяет соответствие маске. Для подходящих файлов выводит имя,
размер и дату изменения. Результат также сохраняется в текстовый
файл-отчёт.

## Что демонстрирует

- рекурсивный обход файловой системы;
- работу с путями и метаданными файлов;
- сопоставление имени файла с маской;
- запись отчёта в файл.

## Структура

```
task_4_haskell/
├── README.md       — этот файл
└── findfiles.hs    — главная программа
```

## Сборка и запуск

Требуется GHC.

```bash
runghc findfiles.hs <каталог> <маска>
```

Пример:

```bash
runghc findfiles.hs . "*.hs"
```

## Формат ввода

Аргументы командной строки:
1. путь к каталогу;
2. маска файлов (например `*.txt`, `*.hs`, `report*`).

## Формат вывода

В консоль:

```
Найдено файлов: 3
./src/Main.hs      | 1234 байт | 2025-01-15 10:23
./src/Utils.hs     |  567 байт | 2025-01-14 18:05
./test/Spec.hs     |  890 байт | 2025-01-13 09:41
```

Файл-отчёт `find_report.txt` содержит те же строки.

## Примечания

Специализированные библиотеки не используются — только стандартные
модули GHC (`System.Directory`, `System.FilePath`, `System.IO`).
