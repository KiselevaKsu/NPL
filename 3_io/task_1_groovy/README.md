# Задача 3.1. Консольный редактор списка контактов

## Тема

Ввод/вывод в консоль и файл.

## Язык

Groovy.

## Условие

Консольная программа для ведения списка контактов. Каждый контакт
содержит имя, телефон и email. Поддерживаются команды:

- `add` — добавить контакт;
- `list` — вывести все контакты;
- `find` — найти контакт по имени;
- `del` — удалить контакт по имени;
- `exit` — выйти из программы.

Контакты хранятся в текстовом файле в простом формате. При запуске
файл читается, после каждого изменения перезаписывается. Есть
проверка корректности ввода.

## Что демонстрирует

- чтение и запись текстового файла;
- разбор простого текстового формата;
- цикл обработки команд с консоли;
- обработку некорректного ввода.

## Структура

```
task_1_groovy/
├── README.md          — этот файл
├── contacts.groovy    — главная программа
└── contacts.txt       — файл с контактами (создаётся автоматически)
```

## Сборка и запуск

Требуется Groovy.

```bash
groovy contacts.groovy
```

## Формат файла контактов

```
name|phone|email
Alice|+79001234567|alice@example.com
Bob|+79007654321|bob@example.com
```

## Формат вывода

```
> add
Имя: Alice
Телефон: +79001234567
Email: alice@example.com
Контакт добавлен.

> list
1. Alice | +79001234567 | alice@example.com

> find
Имя: Alice
Найден: Alice | +79001234567 | alice@example.com
```

## Примечания

Специализированные библиотеки не используются — только стандартные
средства Groovy и JDK (`File`, `Scanner`).
