# Задача 3.2. Частота слов в текстовом файле

[📹 Видео-демонстрация](https://disk.yandex.ru/i/f1gcv5WYCH5Gug)

## Тема

Ввод/вывод в консоль и файл.

## Язык

Perl.

## Условие

Программа читает текстовый файл, разбивает его на слова, считает
частоту каждого слова. Выводит топ-20 самых частых слов в консоль
и дописывает сводку в файл-журнал: дата, имя исходного файла,
общее число слов, топ-20.

## Что демонстрирует

- чтение текстового файла построчно;
- разбиение текста на слова с приведением к нижнему регистру;
- подсчёт частоты через хеш (ассоциативный массив);
- сортировку по убыванию частоты;
- запись отчёта в файл в режиме добавления (append).

## Структура

```
task_2_perl/
├── README.md       — этот файл
├── wordfreq.pl     — главная программа
└── input.txt       — пример входного файла
```

## Сборка и запуск

Требуется интерпретатор Perl (5.10+).

```bash
perl wordfreq.pl input.txt
```

## Формат ввода

Один текстовый файл, путь передаётся аргументом командной строки.

## Формат вывода

В консоль:

```
File: input.txt
Total words: 1234
Top-20:
  1. the        — 56
  2. and        — 41
  ...
```

В файл-журнал `wordfreq.log` дописывается блок с датой, именем файла
и тем же топ-20.

## Примечания

Специализированные библиотеки не используются — только стандартные
средства Perl.
