# Задача 4.4. Эхо-сервер с журналированием обращений

## Тема

Клиент-серверное взаимодействие.

## Язык

ODIN.

## Условие

TCP-сервер, который отвечает на команды клиента:

- `ECHO <text>` — возвращает текст обратно;
- `TIME` — возвращает текущее время сервера;
- `UPPER <text>` — возвращает текст в верхнем регистре.

Каждое обращение клиента (адрес, команда, время) записывается
в файл-журнал на сервере.

## Что демонстрирует

- работу с TCP-сокетами через `core:net` (стандартная библиотека ODIN);
- обработку нескольких клиентов через `core:thread`;
- разбор текстовых команд;
- запись журнала обращений в файл.

## Структура

```
task_4_odin/
├── README.md       — этот файл
├── server.odin     — сервер
└── client.odin     — клиент
```

## Сборка и запуск

Требуется компилятор ODIN.

Сервер:

```bash
odin run server.odin -file
```

Клиент (в другом окне):

```bash
odin run client.odin -file
```

## Формат команд клиента

```
ECHO hello
TIME
UPPER hello world
QUIT
```

## Формат вывода сервера

```
[server] client connected: 127.0.0.1:...
[server] ECHO hello
[server] TIME
[server] UPPER hello world
[server] client disconnected
```

Файл-журнал `server.log`:

```
2026-10-12 14:30:01 127.0.0.1 ECHO hello
2026-10-12 14:30:05 127.0.0.1 TIME
```
