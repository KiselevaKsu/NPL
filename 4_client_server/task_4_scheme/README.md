# Задача 4.4. Сервер заметок с журналированием

## Тема

Клиент-серверное взаимодействие.

## Язык

Scheme.

## Условие

TCP-сервер для хранения заметок. Клиенты подключаются к серверу
и отправляют текстовые команды:

- `ADD <текст>` — добавить заметку;
- `LIST` — вывести список заметок;
- `GET <id>` — получить заметку по номеру;
- `DELETE <id>` — удалить заметку по номеру;
- `QUIT` — отключиться.

Заметки хранятся в памяти сервера. Каждое обращение клиента
(адрес, команда, время) записывается в файл-журнал на сервере.

## Что демонстрирует

- работу с TCP-сокетами;
- обработку нескольких клиентов;
- хранение состояния в памяти;
- запись журнала обращений в файл;
- текстовый протокол обмена.

## Структура


## Сборка и запуск

Требуется Scheme-интерпретатор (например Chicken Scheme, Guile
или Racket в режиме R5RS).

Сервер (Chicken Scheme):

```bash
csc server.scm -o server
./server 8080
```

Клиент:

```bash
csc client.scm -o client
./client 127.0.0.1 8080
```

## Формат команд клиента

```
ADD Купить хлеб
LIST
GET 1
DELETE 1
QUIT
```

## Формат вывода сервера

```
[client 127.0.0.1:54321] ADD Купить хлеб
Заметка #1 добавлена.

[client 127.0.0.1:54322] LIST
Заметки:
  1. Купить хлеб
```

Журнал `server.log`:

```
2025-01-15 10:23:01 127.0.0.1:54321 ADD Купить хлеб
2025-01-15 10:23:05 127.0.0.1:54322 LIST
```

## Примечания

Специализированные библиотеки не используются — только стандартные
средства Scheme (сокеты и файловый ввод/вывод из поставки
интерпретатора).
