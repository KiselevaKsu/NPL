# Задача 4.1. Сервер голосования с рассылкой статистики

## Тема

Клиент-серверное взаимодействие.

## Язык

Rust.

## Условие

TCP-сервер для голосования. Клиенты подключаются к серверу
и могут:

- создать новое голосование с вариантами ответа;
- проголосовать в существующем голосовании;
- запросить текущую статистику.

После каждого голоса сервер рассылает всем подключённым клиентам
обновлённую статистику. Каждый клиент обслуживается в отдельном
потоке.

## Что демонстрирует

- работу с TCP-сокетами (`std::net`);
- многопоточность через `std::thread`;
- разделяемое состояние под `Mutex`;
- рассылку сообщений нескольким клиентам;
- текстовый протокол обмена.

## Сборка и запуск

Требуется `rustc` (или `cargo`).

Сервер:

```bash
rustc server.rs -o server
./server 127.0.0.1:8080
```

Клиент (в другом терминале):

```bash
rustc client.rs -o client
./client 127.0.0.1:8080
```

## Формат команд клиента

```
CREATE <вопрос>|<вариант1>|<вариант2>|...
VOTE <id> <номер_варианта>
STATS <id>
QUIT
```

Пример:

```
CREATE Лучший язык?|Rust|C++|Python
VOTE 1 0
STATS 1
```

## Формат вывода сервера

```
[client 1] CREATE: Лучший язык?
Голосование #1 создано: Лучший язык? [Rust, C++, Python]

Статистика по голосованию #1:
  Rust   — 1
  C++    — 0
  Python — 0
```

## Примечания

Специализированные библиотеки не используются — только стандартная
библиотека Rust (`std::net`, `std::thread`, `std::sync`).
