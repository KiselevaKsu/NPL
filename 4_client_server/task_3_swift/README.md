# Задача 4.3. Сервер учёта задач с синхронизацией состояния

## Тема

Клиент-серверное взаимодействие.

## Язык

Swift.

## Условие

TCP-сервер для совместного ведения списка задач. Несколько клиентов
подключаются к серверу и могут:

- добавить задачу;
- удалить задачу по номеру;
- запросить текущий список задач.

Сервер поддерживает согласованный список задач и после каждого
изменения рассылает всем подключённым клиентам текущее состояние.
Доступ к списку защищён мьютексом.

## Что демонстрирует

- работу с TCP-сокетами через `Network` или BSD-сокеты;
- многопоточность через `DispatchQueue` / `Thread`;
- разделяемое состояние под `NSLock` / `DispatchSemaphore`;
- рассылку состояния нескольким клиентам.

## Сборка и запуск

Требуется Swift (Xcode или swift toolchain).

Сервер:

```bash
swiftc Server.swift -o server
./server 8080
```

Клиент (в другом терминале):

```bash
swiftc Client.swift -o client
./client 127.0.0.1 8080
```

## Формат команд клиента

```
ADD <текст задачи>
DEL <номер>
LIST
QUIT
```

Пример:

```
ADD Купить хлеб
ADD Позвонить маме
DEL 1
LIST
```

## Формат вывода сервера

```
[client 1] ADD: Купить хлеб
Текущий список:
  1. Купить хлеб

[client 2] ADD: Позвонить маме
Текущий список:
  1. Купить хлеб
  2. Позвонить маме

[client 1] DEL: 1
Текущий список:
  1. Позвонить маме
```

## Примечания

Специализированные библиотеки не используются — только стандартные
модули Swift (`Foundation`, `Network` или BSD-сокеты).
