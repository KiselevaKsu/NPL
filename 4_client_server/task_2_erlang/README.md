# Задача 4.2. Сервер-викторина

## Тема

Клиент-серверное взаимодействие.

## Язык

Erlang.

## Условие

TCP-сервер для викторины. Сервер рассылает всем подключённым
клиентам вопрос с несколькими вариантами ответа, принимает ответы,
сравнивает с правильным и после каждого вопроса рассылает итоговую
статистику: сколько ответили верно, сколько нет, процент правильных
ответов.

Каждый клиент обслуживается в отдельном процессе (акторная модель).

## Что демонстрирует

- работу с TCP-сокетами через `gen_tcp`;
- акторную модель: отдельный процесс на клиента;
- рассылку сообщений нескольким клиентам;
- подсчёт статистики по ответам;
- текстовый протокол обмена.

## Структура

```
task_2_erlang/

```

## Сборка и запуск

Требуется Erlang/OTP.

Сервер:

```bash
erlc server.erl
erl -noshell -s server start -s init stop
```

Клиент (в другом терминале):

```bash
erlc client.erl
erl -noshell -s client start -s init stop
```

## Формат обмена

Сервер рассылает:

```
ВОПРОС: Столица Франции?
1) Париж
2) Лондон
3) Берлин
```

Клиент отправляет номер варианта:

```
1
```

Сервер после сбора ответов рассылает:

```
Правильный ответ: 1
Верно: 2, неверно: 1, процент правильных: 66.7%
```

## Формат вывода сервера

```
[server] клиент подключён: 127.0.0.1:54321
[server] разослан вопрос: Столица Франции?
[server] получен ответ от клиента 1: 1
[server] статистика: верно 2, неверно 1, 66.7%
```

## Примечания

Специализированные библиотеки не используются — только стандартные
модули Erlang/OTP (`gen_tcp`, `io`, `lists`).
