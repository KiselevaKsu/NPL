# Задача 5.2. INI → JSON

## Тема

Конвертация данных из одного формата в другой.

## Язык

Lua.

## Условие

Дан INI-файл. Нужно преобразовать его в JSON-объект вида:

```json
{
  "section": {
    "key": "value"
  }
}
```

Разбор INI должен учитывать:
- секции `[section]`;
- пары `key=value`;
- комментарии `;`;
- пустые строки.

JSON-вывод должен быть с корректным экранированием строк и отступами.

## Что демонстрирует

- собственный парсер INI;
- построение вложенной структуры (таблицы таблиц в Lua);
- генерацию JSON с экранированием и отступами;
- запись результата в файл.

## Структура

```
task_2_lua/
├── README.md       — этот файл
├── ini2json.lua    — главная программа
└── input.ini       — пример входного файла
```

## Сборка и запуск

Требуется интерпретатор Lua (5.3+).

```bash
lua ini2json.lua input.ini output.json
```

## Формат ввода

Пример `input.ini`:

```
; комментарий
[database]
host = localhost
port = 5432

[server]
name = "main server"
debug = true
```

## Формат вывода

`output.json`:

```json
{
  "database": {
    "host": "localhost",
    "port": "5432"
  },
  "server": {
    "name": "main server",
    "debug": "true"
  }
}
```

## Примечания

Специализированные библиотеки не используются — только стандартные
средства Lua (`io`, `string`, `table`).
