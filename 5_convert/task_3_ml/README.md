# Задача 5.3. Пользовательский формат «список игроков» → JSON

## Тема

Конвертация данных из одного формата в другой.

## Язык

ML (Standard ML, компилятор SML/NJ).

## Условие

Дан текстовый файл со списком игроков в пользовательском формате:

```
player: name=Alice level=10 score=1500
player: name=Bob level=5 score=800
```

Нужно разобрать его и преобразовать в JSON-массив объектов:

```json
[
  {"name": "Alice", "level": 10, "score": 1500},
  {"name": "Bob", "level": 5, "score": 800}
]
```

Числовые поля (`level`, `score`) выводятся как числа, строковые
(`name`) — как строки.

## Что демонстрирует

- чтение текстового файла построчно;
- разбор пользовательского формата;
- работу с токенами и разбиением строк;
- генерацию JSON;
- запись результата в файл.

## Структура

```
task_3_ml/
├── README.md         — этот файл
├── players2json.sml  — главная программа
└── input.txt         — пример входного файла
```

## Сборка и запуск

Требуется SML/NJ.

```powershell
sml players2json.sml
```

## Формат ввода

Строки вида:

```
player: name=Alice level=10 score=1500
```

Поля разделены пробелами, пары `ключ=значение`.

## Формат вывода

Файл `output.json`:

```json
[
  {"name": "Alice", "level": 10, "score": 1500},
  {"name": "Bob", "level": 5, "score": 800}
]
```
