# Задача 5.4. CSV → JSON

[📹 Видео-демонстрация](https://disk.yandex.ru/i/9r7PxM6oyEia9Q)

## Тема

Конвертация данных из одного формата в другой.

## Язык

Lisp (SBCL, Steel Bank Common Lisp).

## Условие

Дан CSV-файл. Нужно преобразовать его в JSON-массив объектов.
Первая строка CSV считается заголовком и задаёт имена полей.
Разбор CSV должен учитывать кавычки, запятые внутри полей и
удвоенные кавычки (`""` → `"`).

## Что демонстрирует

- собственный парсер CSV (без сторонних библиотек);
- обработку кавычек и экранирования;
- генерацию JSON с экранированием специальных символов;
- запись результата в файл.

## Структура

```
task_4_lisp/
├── README.md     — этот файл
├── csv2json.lisp — главная программа
└── input.csv     — пример входного файла
```

## Сборка и запуск

Требуется SBCL.

```bash
sbcl --script csv2json.lisp
```

Или:

```bash
sbcl --load csv2json.lisp --eval '(csv2json:main)' --quit
```

## Формат ввода

CSV-файл с заголовком в первой строке:

```
name,age,city,note
Alice,30,"Moscow, RU","loves ""cats"""
Bob,25,SPb,programmer
```

## Формат вывода

Файл `output.json`:

```json
[
  {"name": "Alice", "age": "30", "city": "Moscow, RU", "note": "loves \"cats\""},
  {"name": "Bob", "age": "25", "city": "SPb", "note": "programmer"}
]
```

Все значения выводятся как строки (без автоматического приведения типов).

## Примечания

Специализированные библиотеки не используются — только стандартная
библиотека SBCL.
