# Задача 5.4. CSV → JSON

## Тема

Конвертация данных из одного формата в другой.

## Язык

Zig.

## Условие

Дан CSV-файл. Нужно преобразовать его в JSON-массив объектов.
Первая строка CSV считается заголовком и задаёт имена полей.
Разбор CSV должен учитывать кавычки, запятые внутри полей и
удвоенные кавычки (`""` → `"`).

Пример входа:

```
name,age,city
Alice,30,"Moscow, RU"
Bob,25,"Saint ""Petersburg"""
```

Пример выхода:

```json
[
  {"name": "Alice", "age": "30", "city": "Moscow, RU"},
  {"name": "Bob", "age": "25", "city": "Saint \"Petersburg\""}
]
```

## Что демонстрирует

- собственный парсер CSV (без сторонних библиотек);
- обработку кавычек и экранирования;
- генерацию JSON с экранированием специальных символов;
- запись результата в файл.

## Структура

```
task_4_zig/
├── README.md     — этот файл
├── csv2json.zig  — главная программа
└── input.csv     — пример входного файла
```

## Сборка и запуск

Требуется компилятор Zig (0.11+).

```bash
zig build-exe csv2json.zig
./csv2json input.csv output.json
```

## Формат ввода

CSV-файл с заголовком в первой строке.

## Формат вывода

JSON-массив объектов, по одному на каждую строку CSV. Все значения
выводятся как строки (без автоматического приведения типов), чтобы
не терять ведущие нули и неоднозначные случаи.

## Примечания

Специализированные библиотеки не используются — только стандартная
библиотека Zig (`std.io`, `std.fs`, `std.mem`, `std.ArrayList`).
